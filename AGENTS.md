# SugboGo UI/UX Guidelines

SugboGo already has an established design system. Treat the existing implementation, theme tokens, components, spacing, typography, colors, borders, radii, animations, and interaction patterns as the source of truth.

Do not generate or introduce a new design system.

Before suggesting UI changes, inspect the existing implementation and improve it within the established visual language.

When proposing UI/UX improvements:
- Preserve the existing SugboGo visual identity.
- Reuse existing components and design tokens whenever possible.
- Prefer refinement over replacement.
- Do not introduce unrelated colors, typography, spacing systems, or interaction patterns.
- Identify specific weaknesses in the current implementation before proposing changes.
- Explain why a proposed change improves usability, hierarchy, accessibility, or consistency.
