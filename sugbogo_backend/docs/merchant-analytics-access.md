# Merchant analytics access

Standard analytics includes Visibility trends (profile visits, impressions and visitor accounts), Review insights, current specialty vouches, and route-planning activity.

Merchant Plus adds Where visits came from (discovery-source breakdown), visit timing, Pocket trends, specialty trends, review performance, peer comparisons, business recommendations, and PDF export. Review insights remains Standard.

Existing endpoint URLs are retained for compatibility: `/premium/visibility/` now allows authenticated merchants without Plus; `/standard/discovery-sources/` now requires Plus. Route names are historical, not access policy. Both continue to enforce merchant identity and owned-business scope.
